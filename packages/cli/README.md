# @esuiss/uim

Add esuiss components to Expo projects.

```bash
npx @esuiss/uim@latest init
npx @esuiss/uim@latest add dialog
npx @esuiss/uim@latest add button --diff
npx @esuiss/uim@latest add button --overwrite
```

`init` sets up Uniwind (Tailwind CSS v4), the `@/*` import alias, the theme stylesheet, the portal host, and the button. Requires Expo and TypeScript.
